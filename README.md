## Featured Projects

### 1. Moi Account Management System

A web-based account management and search system designed to make account records easier to find and manage.

**Key features**
- Search account records using English and Tamil.
- Fuzzy matching to handle spelling variations.
- Voice-based search support.
- Responsive interface for mobile and desktop devices.
- Protected account status updates.

**Technologies:** React, JavaScript, Node.js, Express.js, MySQL, Axios, Fuse.js.

### 2. Milk Manager

A React Native mobile application designed for households that purchase milk daily. It helps users record milk quantities, amounts, dates, and times while tracking totals and payment balances.

**Key features**
- Record daily milk quantities and amounts.
- Track daily and accumulated totals.
- Monitor paid and unpaid balances.
- Simplify manual calculations and record keeping.

**Technology:** React Native.

### 4. AI Smart Vision

An AI-assisted accessibility project designed to help visually impaired people better understand and navigate their surroundings.

- Voice-based assistance and guidance.
- Indian currency recognition.
- Colour identification.
- Support for understanding nearby objects and surroundings.
